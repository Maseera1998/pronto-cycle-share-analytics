# 🚲 Pronto Cycle Share Analytics Dashboard

An interactive Power BI analytics solution analyzing Seattle's Pronto Cycle Share bike-sharing program across ridership trends, weather impact, station performance, and user demographics.

## 📊 Dashboard Pages
| Page | Focus |
|------|-------|
| Executive Summary | KPI cards — Total Trips, Avg Duration, Member %, YoY Growth |
| Weather Impact Analysis | Trip volume vs. temperature & precipitation |
| Station & Route Analysis | Geospatial maps, top routes, hour×weekday heatmap |
| User Demographics | Age, gender, user type, trip duration breakdown |
| Growth Analysis | CAGR, cumulative growth, 2014–2016 trend |

## 🛠️ Tools & Techniques
- **Tool**: Microsoft Power BI Desktop
- **DAX Measures**: YoY growth %, Weather Impact %, Station Utilization Rate, CAGR, Rush Hour segmentation
- **Visuals**: KPI Cards, Line Charts, Bar/Column Charts, Donut Charts, Maps, Scatter Plot, Waterfall, Pivot Table

## 📁 Files
- `Pronto_Cycle_Share_Analytics_Dashboard.pbix` — Main Power BI file

## 🔍 Key Insights
- Member riders are significantly more weather-resilient than casual users
- Evening rush (4–7 PM) outpaces morning rush (7–9 AM) in trip volume
- Station utilization is highly concentrated in a small number of high-traffic nodes
